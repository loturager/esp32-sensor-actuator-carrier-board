\# ESP32 Sensor/Actuator Carrier Board



A professional KiCad-based two-layer PCB project for an ESP32 DevKit 30-pin module, designed for sensor interfacing, serial communication, external power input and low-side actuator control.



\## Project Status



\- Revision: RevA v0.1

\- Current phase: Block architecture

\- Previous phase: Requirements frozen

\- Next phase: KiCad schematic capture



\## Main Features



\- ESP32 DevKit 30-pin carrier board

\- External VIN input from 7 V to 12 V

\- Adjustable buck converter stage for 5 V generation

\- 3.3 V rail supplied by the ESP32 DevKit

\- I2C, UART and GPIO expansion connectors

\- Low-side N-channel MOSFET output for external load control

\- Power indication LED

\- Test points for validation and debugging

\- Two-layer PCB with top and bottom GND planes
